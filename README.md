# Web Page Design Using External CSS

## Project Description

This project demonstrates the design of a simple and attractive web page using **HTML and External CSS**. The page is formatted with a background image, different text colors, and borders around the text to improve its appearance.
https://shimmering-kulfi-25051d.netlify.app/

## Features

* Background image for the web page
* Different text colors and font styles
* Borders around headings and paragraphs
* Proper spacing and alignment
* External CSS file for styling
* Simple and user-friendly design

## Technologies Used

* **HTML5** – To create the structure of the web page
* **CSS3** – To provide styling and formatting

## Project Structure

```text
Web-Page-Using-External-CSS/
│
├── index.html
├── style.css
└── background.jpg
```

## Output

The final web page contains a background image with properly formatted text, different colors, and attractive borders using an external CSS stylesheet.

## Conclusion

This project shows how **external CSS** can be used to make a basic HTML web page more attractive, organized, and visually appealing.
